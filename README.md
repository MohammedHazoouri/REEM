# The Reem Edition — birthday website

An English-language, two-section birthday tribute for Reem, designed like an architectural moodboard with woodland deer details. Built with plain HTML, CSS and JavaScript; no build step or package installation is needed.

## Run it

Unzip the folder and open `index.html` in a modern browser. You can also run a static file server from the project folder if you prefer.

## Make it personal

- Replace the five images in `assets/` while keeping their filenames. They are original concept visuals, not photographs of Reem.
- Change the birthday text, gallery labels, captions, or footer in `index.html`.
- The celebration buttons, progress line, scroll reveals and image lightbox are implemented in `script.js`.
- `styles.css` contains the responsive layout, color palette, animation and reduced-motion support.

The page uses Google Fonts when internet access is available and falls back to system fonts when offline.
